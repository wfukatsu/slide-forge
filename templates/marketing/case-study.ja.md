## 1. 公開許諾

**ここが埋まるまで、顧客提示物に載せない。**

| 項目 | 内容 |
|---|---|
| 許諾の状態 | 未取得 / 申請中 / **取得済**（日付: ） |
| 許諾をくれた相手（部署・役職） | |
| 許諾の範囲 | 社名の掲載 / ロゴの掲載 / 数値の掲載 / 登壇 / リファレンスコール |
| **許諾していない範囲**（明示） | |
| 許諾の証跡（メール・書面の所在） | |
| 再確認が必要になる条件 | 担当者の異動 / 契約更改 / 掲載媒体の追加 |

**許諾の範囲を超えて使わない。** 「社名の掲載は可、数値は不可」はよくある条件で、
範囲を書いていない事例は**全部不可として扱う**。

## 3. 数値と出典

**1 行 = 1 数値。出典の無い行を作らない。**

| # | 指標 | 導入前 | 導入後 | 出典（媒体名 / URL / 日付） | 最終確認日 | 判定 |
|---|---|---|---|---|---|---|
| 1 | | | | | | 有効 / 要更新 |

- **導入前の値が無い数値は「効果」ではない。** 片側だけなら、そう書く
- 「約 1/5」「70% 削減」のような公表表現は、**そのまま**使う
- 出典が複数ある場合は、**最も一次に近いもの**（顧客の発表 > 媒体記事）を先に書く
