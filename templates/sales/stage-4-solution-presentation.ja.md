## 14. ステージ移行判断

| ゲート ID | 移行条件 | 判定 | 顧客側の証拠 |
|---|---|:-:|---|
| `g4.product-selected` | Scalar 製品が選定されている（シート記載） | unmet | |
| `g4.budget-agreed` | 予算・購入金額をおおよそ合意し、予算確保が確認できている（シート記載） | unmet | |
| `g4.partner-decided` | 導入パートナーが決定している（シート記載） | unmet | |
| `g4.closing-reviewed` | 契約までの課題とタスクを Deal Desk でレビューしている | unmet | |

判定は `met` / `partial` / `unmet` で書く（台帳の `GATE_STATUS` と同じ語彙）。
**`met` にできるのは、顧客側の証拠が書ける場合だけ。**

**判定**: ステージ 5 へ移行する / 継続する / 失注・保留（理由: ）

失注または保留になった場合は、**`deal-log.md` §4 の失注・保留の記録を必ず埋める**。
敗因・分かれ目になった評価軸・再アプローチの条件を残さずに商談を閉じない。

**ステージ 5 へ引き渡すもの**: 最終スコープ ／ 役割分担表 ／ 詳細見積 ／
見積もりの前提条件 ／ パートナー商流の形
