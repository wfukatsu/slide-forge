# 価格水準

各セグメント・各オファーに「いくら付けるか」を決める手順を扱う。価値カスケード（価値の創造 → 価値の伝達 → 価格構造 → 価格ポリシー → 価格水準 → 価格競争）の 5 段目で、価格構造（[price-structure.md](price-structure.ja.md)）が決まった後、新製品の初期価格や既存製品の値上げ・値下げを決めるときに使う。

## 要点

- 価格水準は価値創造と価値獲得の交点で決める。財務と営業の見方を妥協させず同じ手順で融合させる。
- 手順は 6 段階: 価格レンジ → 戦略的選択 → 損益分岐販売変化率 → 価格弾力性 → 心理的要因 → 新価格の伝達（[1] Exhibit 6-1）。
- 天井は総経済価値（total economic value: 次善の競合代替品の価格＋差別化価値）。床は、正の差別化製品なら次善の競合代替品（next-best competitive alternative: 自社を選ばない顧客が選ぶ最善の選択肢）の価格、負の差別化製品なら増分コスト（incremental cost: その販売で追加で発生するコスト）である。
- 性能の改善率と取れるプレミアム率は一致しない。プレミアムは差別化価値（differentiation value: 次善の競合代替品との価値の差を金額にしたもの）から出す。
- 戦略はスキミング（skimming: 高価格で価格に鈍感な層から取る）、浸透価格（penetration pricing: 低価格で数量を取る）、中立価格（neutral pricing: 価格を購買判断の主因にしない）。能力と市場ポジションを踏まえれば、たいてい 1 つに絞られる。
- 需要曲線を推定する代わりに、利益を保つのに必要な最小の販売変化を計算する。それは貢献利益率（価格に占める貢献利益の割合）でほぼ決まる。
- 価格感応度（price sensitivity）は、価値の伝え方で動かせる変数である。値上げの成否は公正さの伝え方で決まる。

## 判断基準・使い分け

### 価格レンジ

| 差別化 | 天井 | 床 |
|---|---|---|
| 正 | 総経済価値＝次善の競合代替品の価格＋差別化価値 | 次善の競合代替品の価格（下回ると価格戦争を招く） |
| 負 | 総経済価値（競合価格より低い） | 増分コスト（[1] は変動費と表記） |

- 天井で売ると乗り換える理由が残らない。天井との差が購入インセンティブである。
- 戦略・損益分岐・弾力性・心理的要因で絞った実現可能な価格レンジは、理論上のレンジよりずっと狭い。
- レンジはセグメントごとに引く。重なれば 1 オファー＋価格フェンス、重ならなければ別階層にする（[price-structure.md](price-structure.ja.md)）。

### 戦略の選び方

| 戦略 | 成立条件 | 失敗パターン |
|---|---|---|
| スキミング | 差別化属性を高く評価する価格に鈍感な層が十分いる／高価格の理由を伝える投資ができる／特許・ブランド・流通で低価格代替を防げる、または低価格が参入抑止にならない／断念客が自社の下位品に流れる | 模倣され、高価格が参入の呼び水になる |
| 逐次スキミング | 再購入率が低く、買った顧客は去る。鈍感な層から順に段階的に値下げ | 頻繁な値下げで買い控え。間隔を空け、下位モデル投入と同時に下げる |
| 浸透価格 | 市場の大部分が低価格なら乗り換える／貢献利益率が高い（90% なら 10% 値下げに必要な数量増は 12.5%）／競合が追随しない理由がある（コスト・資源優位、補完品で回収するロスリーダー、反応を招かない小ささ） | 競合が追随し利益が消える。顧客が「ディール」待ちに条件づけられる |
| 中立価格 | どちらの条件も満たさない／製品・ブランド・サービスで競う | 競合と同額と誤解する（中立はプレミアムでも成立する） |

浸透価格は最も安易に選ばれ最も根拠が乏しい。「なぜ競合は追随しないのか」に答えられなければ採らない。「まず安く後で上げる」は初期価格が公正さの基準になるので難しい。

### 価格感応度に影響する要因（[1] p.147–148 の囲み記事）

| 要因 | 価格感応度が下がる条件 |
|---|---|
| 参照価値 | より高価な代替品と比べる枠組みを作れる（新カテゴリーは初期価格が参照点） |
| スイッチングコスト | 乗り換えの金銭・非金銭費用が大きい |
| 比較の困難さ | 比較・試用が難しく、期待便益を得られない損失が大きい |
| 最終便益の重要性 | 重要な成果の総費用のごく一部、または失敗の代償が大きい |
| 価格・品質知覚 | 価格が品質の代理指標になる |
| 支出の大きさ | 予算に占める割合が小さい（大きいと上がる） |
| 費用の分担 | 他者（保険、雇用主）が一部を払う |
| 取引価値 | 「妥当な価格」より安いと感じる取引効用がある |
| 知覚された公正さ | 価格・値上げがコストや価値で正当化されている（範囲外なら急上昇） |

価値推定の代わりにはしない。レンジ内の位置の論拠と伝え方の設計に使う。

### 新製品と既存製品

| 観点 | 新製品 | 既存製品 |
|---|---|---|
| 出発点 | 見込み客調査による価値推定。最後の手段は差別化価値の 50:50 分割 | 現行価格 |
| 参照価格 | 初期価格が参照点になり、後で上げにくい | 変更は公正さが問われる |
| 弾力性の情報 | 統制実験・購買意向調査・構造化推論（[measurement.md](measurement.ja.md)） | 過去の自然実験。現在に当てはまるかは判断 |
| 主なリスク | 価値の無理解（教育で補う）、リスク認識（保証で補う） | 値上げ時の需要は値下げ時より弾力的 |

## 手順

1. **レンジを定義する**。セグメントごとに総経済価値（[economic-value.md](economic-value.ja.md)。`scripts/pricing/eve_calc.py` は価値ドライバーからセグメント別に計算する）、次善の競合代替品の価格、増分コストを並べる。
2. **戦略を選ぶ**。成立条件を 1 つずつ検証し、根拠を書き残す。
   ```
   価値獲得率 = (価格 − 次善の競合代替品の価格) / 差別化価値
   ```
3. **損益分岐販売変化率（価格変更後も貢献利益の総額を保つのに必要な販売量の変化率）を計算する**。`scripts/pricing/breakeven.py` が候補価格ごとに計算する（詳細は [financial-analysis.md](financial-analysis.ja.md)）。
   ```
   損益分岐販売変化率 = −ΔP / (CM + ΔP)
     ΔP: 価格変化、CM: 変更前の単位あたり貢献利益（contribution margin。同じ単位、率なら価格比）
   例: CM 50%, +5% → −5/55 = −9.1%（9.1% まで失ってよい）
       CM 50%, −5% → +5/45 = +11.1%
       CM 50%, −25% → +25/25 = +100%
   価格弾力性 E = %ΔQ / %ΔP（通常は負）
   ```
   値下げ幅が貢献利益率以上なら、どれだけ売っても利益は戻らない。
4. **弾力性を見積もる**。必要な販売変化が起こりそうかを判断する。過去の自然実験、営業への質問（値引き権限と引き換えに損益分岐分の目標増を受けるか）、[measurement.md](measurement.ja.md) の手法を使う。確信がなければ小刻みに変更して反応を確かめる。
5. **心理的要因を考える**。効いている価格感応度の要因を特定し、参照価値の設定、保証、単位の言い換えで価格感応度を下げる。リスク認識が障害なら返金・成果保証で価格を価値に連動させる。
6. **競合反応を確認する**（[1] の 6 段階への追加。[price-competition.md](price-competition.ja.md)）。
7. **最終価格を選び、伝える**（次の節）。

### 新価格の伝達

1. **全顧客に同時に、コストと結びつけて説明する**。可能なら公表指数に連動させる（指数連動価格）。
   ```
   値上げ率 = 投入コストの上昇率 × 価格に占めるそのコストの比率
   例: エネルギー +24%、比率 10% → 2.4%
   ```
2. **事前通知する**。数か月前に通知し旧価格での先買い余地を与える。前回値上げからの期間、業界指数との比較、追加利益の使い道を示す。
3. **日和見的にならない**。「増量すれば値上げ免除」は根拠が不当だったと伝え、報復を招く。
4. **価格以外の手段を検討する**。サーチャージ、内容量の変更、低価格ブランドの受け皿、オフピークへの誘導、配合変更。
5. **安すぎた価格の是正**は「今後すべての価格を価値に合わせる」と説明し、コストを下げる行動（長期契約など）で低価格を獲得できる道か、旧価格のアンバンドル版を用意する。

## チェックリスト

- [ ] セグメントごとに天井と床が数値で示されている
- [ ] 正の差別化製品の床に変動費を使っていない
- [ ] 戦略の成立条件が検証され、浸透価格なら「競合が追随しない理由」がある
- [ ] 候補価格ごとに損益分岐販売変化率があり、実現可能性を根拠付きで評価した
- [ ] 効いている価格感応度の要因と、それを下げる施策が特定されている
- [ ] 競合反応の検討がある
- [ ] 新価格の伝達計画（根拠、通知時期、指数連動の可否、代替手段）がある

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| コストプラスと競合追随の妥協で決める | 天井・床を価値で定義し 6 段階で揃える |
| 「x% 優れているから x% のプレミアム」 | 差別化価値を金額で推定する |
| 根拠なく浸透価格を選ぶ | 追随されない理由と必要数量増を示す |
| 天井いっぱいに付ける | 購入インセンティブを残す。無理解には教育、リスク認識には保証 |
| 新製品を安く出して後で上げる | 価値に基づく価格で出し、導入誘因は期間限定クレジットや保証で与える |
