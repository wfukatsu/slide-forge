# 価値と価格のコミュニケーション
このドキュメントは、製品の価値を顧客に理解させ、価格を受け入れてもらう伝え方を扱う。価値カスケード（価値の創造 → 価値の伝達 → 価格構造 → 価格ポリシー → 価格水準 → 価格競争）の2段目にあたり、経済的価値を知覚価値に変える段である。経済的価値は十分あるのに「高い」と言われるときや、価値メッセージ、価値計算ツール、価格の見せ方、B2Bの関係者別メッセージを設計するときに読む。

## 要点
- 価値コミュニケーションの目的は3つある。便益を理解させること、支払意思額（willingness-to-pay、顧客が払ってもよいと考える最大額）を上げること、購買確率を上げることである。
- 価値は放っておくと伝わらない。売り手は機能の羅列に逃げがちで、B2Bの購買担当者は安い方を選べば社内で説明が楽になる。売り手の仕事は、買い手がプレミアムを社内で正当化できる材料を渡すことである（[1] p.56–57）。
- メッセージは2軸で決める。便益の種類（経済的か心理的か）と、買い手の関与度（購買判断にかける検討の深さ）である。経済的便益ならEVE（経済的価値の推定。[economic-value.md](economic-value.ja.md)）に基づく定量メッセージ、心理的便益なら感情に訴えるメッセージを使う。
- 知覚価値（買い手が実際に認識している価値）と経済的価値の差が大きいときほど伝達の効果が大きい。市場経験が浅い顧客、革新的な便益、気づきにくい便益（短納期による在庫削減など）がこれにあたる。
- 現実の買い手はヒューリスティクス（経験則）で判断する。競合参照、スイッチングコスト、比較困難、最終便益、価格品質、支出、共有コスト、取引価値、公正性の9つの効果が価格感応度を系統的に動かす（[1] p.64–73）。
- 同じ価格でも、参照点の置き方（デコイ、比較対象の置き換え、単位の言い換え）で割安にも割高にも見える。デコイ（囮）は、ほかの選択肢を妥当に見せるために置く高価格の選択肢である。
- B2Bでは全社の価値を関係者ごとの損得に分解し、適切な人に適切な時点で届ける。

## 判断基準・使い分け

### 関与度 × 便益タイプ
| | 経済的便益 | 心理的便益 |
|---|---|---|
| 高関与 | 定量的な価値の論証。顧客ごとのEVE、価値計算ツール、TCO（総保有コスト）比較、導入実績。例: 経営コンサルティング、航空機エンジン、医療機器 | 安心と証拠。デモ、保証、同業の推薦、体験入会、失敗リスクの提示。例: 減量プログラム、贈答品 |
| 低関与 | 購買時点での短い経済的主張（「年間X円の節約」「寿命2倍」）。例: 省エネ電球、長寿命電池 | フレーミングと手がかり。ブランド、試しやすさ、パッケージ、参照点。例: 化粧品、日用品 |

関与度は、金額が大きいほど、また他人の目に触れる場面で使うほど高くなる。同じ製品でも購買機会によって象限が変わる。ほとんどの購買は両方の要素を持つので、経済的と心理的の両方の便益を持つ製品では両方のメッセージを組み合わせる。B2Bの新製品の多くは左上（高関与・経済的便益）に入るので、EVEのアルゴリズムから価値計算ツールを作り、営業が顧客の数字をその場で入れられるようにする。

### 価格感応度に効く9つの効果
| 効果 | 感応度が下がる条件 | 使い方 |
|---|---|---|
| 競合参照 | 比較対象が高価格のもの、または中位に見えるとき | 置き換える代替品と総コストを明示する。上位にデコイを置く |
| スイッチングコスト | 乗り換えに製品固有の再投資が要るとき | 認定、教育、移行の負担を定量化して示す |
| 比較困難 | 代替品を比べにくいとき | 実績と評判を強調する。単価の比較を自ら促さない |
| 最終便益 | 最終的な成果が大きく、失敗のコストが高いとき | 製品を大きな成果のうちの小さな費用として描く |
| 価格品質 | 品質の手がかりが他にないとき、排他性が価値になるとき | 安売りで品質シグナルを壊さない |
| 支出 | 支出額や予算に占める比率が小さいとき | 1日あたり、1件あたりの単位に言い換える |
| 共有コスト | 自己負担の割合が小さいとき（保険、経費、税控除） | 償還や経費処理の方法を示す |
| 取引価値 | 支払額が参照価格（買い手が妥当・公正と考える価格）より低く感じられるとき | 定価を先に示し、値引きを見える形で提示する |
| 公正性 | 値上げの理由がコスト上昇など正当に見えるとき | 市場支配力による値上げを避ける。同じ額なら追加料金より割引の廃止を選ぶ |

## 手順
1. 知覚価値と経済的価値の差を測る。[economic-value.md](economic-value.ja.md) で出した総経済価値と、顧客の発言や失注理由から推測した知覚価値を並べる。差が大きければ伝達が主な打ち手になる。
2. セグメントごとに象限を判定する。関与度と便益タイプを決め、上の表からメッセージ形式を選ぶ。
3. 参照点を設定する。何を置き換えるのか、その総コストはいくらかを先に示し、価格はそれと比べさせる。機能表では比べさせない。
4. 比較の単位を顧客が価値を感じる単位に言い換え、差別化価値が価格差を上回ることを示す。
   ```
   単位価格 = 年間価格 / (ユーザー数 × 稼働日数)   例: 1ユーザー1日あたり
   正味の効果 = 差別化価値 − 価格差
     例: 薬剤溶出ステント（価格3,500ドル、従来型の2倍）
         再狭窄率の差 15% × 再手術 30,000ドル = 4,500ドル > 価格差 1,750ドル
   ```
5. 経済的便益の場合は価値計算ツールを作る（[1] Exhibit 3-3）。入力（顧客が自分の数字に置き換える前提）と計算（ドライバーごとの金額と合計）を分け、前提をすべて見えるようにする。顧客と一緒に修正できる形にする。
6. 心理的便益の場合は、推定金額をメッセージに入れない。顧客が考えていなかった高価値の便益、または体験前には判断しにくい性能を印象づける（保証、デモ、推薦）。
7. 価格の見せ方を決める。推奨プランの上に意図的なプレミアム選択肢を置く。高価格の理由（希少な原料、サービス水準、保証）を説明する。値引きは定価を示したうえで見える形にする。
8. B2Bでは関係者ごとに分解する。関係者 × 価値要素のマトリクスに＋と−をつけ（[1] Exhibit 3-4）、否定的な人や無関心な人への個別メッセージと、購買プロセスのどの時点でそれを届けるかを決める。
9. 値引き要求への対応と、ギブ・ゲット（give-get、値引きなどの譲歩と引き換えに顧客から見返りを得る規則）は [pricing-policy.md](pricing-policy.ja.md) に回す。

## チェックリスト
- [ ] メッセージが機能ではなく、顧客の経済性や感情にとっての便益で書かれている
- [ ] セグメントごとに関与度と便益タイプの象限が明示されている
- [ ] 置き換える代替品とその総コストが参照点として示されている
- [ ] 経済的便益の主張に、式、前提、出所がある
- [ ] 価値計算ツールの入力を顧客の数字に置き換えられる
- [ ] 心理的便益を無理に金額化していない
- [ ] 価格の単位が顧客の価値の感じ方に合っている
- [ ] 高価格の理由が説明され、公正性を損なう値上げの形になっていない
- [ ] B2Bの関係者ごとの損得と、それぞれへのメッセージがある
- [ ] 購買担当者が社内でプレミアムを正当化できる資料になっている

## よくある失敗と対処
| 失敗 | 対処 |
|---|---|
| 仕様を並べて、便益への翻訳を買い手に任せる | 機能 → 便益 → 金額（または感情）の順に翻訳する |
| 知覚価値が低いことを理由に値下げする | 価格を保ったまま教育する。値下げは経済的価値そのものが足りないときに限る |
| 心理的価値に根拠の薄い数字をつける | 個人差が大きいので定量化せず、証拠と体験で伝える |
| 購買担当者だけに売り込む | 価値を実感する現場の責任者に届け、購買担当者には正当化の材料を渡す |
| 最初の提示で即決させて取引価値を下げる | 定価と価値を先に示し、見返りのある譲歩として条件を提示する |
| 安売りキャンペーンを繰り返す | 価格品質効果と参照価格を壊す。構造（下位の階層）で対応する（[price-structure.md](price-structure.ja.md)） |
| 需要の高いときに市場支配力を背景に値上げする | 将来の取引への影響を考える。値上げの理由と形（割引の廃止、容量の調整）を選ぶ |
