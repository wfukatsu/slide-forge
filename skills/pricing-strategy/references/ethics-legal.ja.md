# 価格の倫理と法的制約

価格施策の倫理と法的制約の論点を扱う。価値カスケード（価値の創造 → 価値の伝達 → 価格構造 → 価格ポリシー → 価格水準 → 価格競争）のすべての段にかかる制約であり、価格戦略、割引方針、再販・流通施策、競合への対応を最終化する前のレビューで使う。これは法務レビューにかける論点のリストであり、法的助言ではない。法律の記述は米国の反トラスト法が前提で、日本や EU の案件は必ず現地の弁護士に確認してもらう。

## 要点
- 価格案は3つの観点で検討する。「儲かるか」「倫理的と見なされるか」「合法か」である。問題のある方針の多くは、小さな修正で収益性と防御可能性を両立できる。
- 倫理の線は5段階のどこかに引く。引く位置は、曖昧な状況に直面する前に決め、割引方針に明記する。
- 競合同士の価格協定（水平的価格協定）は当然違法（per se illegal、行為の存在を示せば違法とされる）である。価格の情報交換や、合意を推認させる行動も避ける。
- 再販価格の合意は、*Khan*（1997）と *Leegin*（2007）以降、合理の原則（rule of reason、競争促進効果と反競争効果を比べて判断する）で判断される。合意を伴わない一方的な方針なら、*Colgate* 原則のもとでより安全である。
- 価格差別（ロビンソン・パットマン法）が違法になるのは、5つの要件がすべて揃ったときだけである。対象は物品に限られ、競合関係にない顧客は対象外である。抗弁は3つある（コスト正当化、競争対抗、状況変化）。
- 販促差別は価格差別より厳しい。競合する再販業者には、比例的に平等な条件で販促を提供しなければならない。
- 略奪的価格設定は、コスト割れに加えて損失回収の蓋然性を立証しなければならないため、ほとんど成立しない。ただし、浸透価格（penetration pricing、低価格で数量とシェアを取る戦略）を「競合排除のため」と記した社内文書は危険である。
- 価格の根拠（コスト差、競合価格、価値差）を記録して残すことが、すべての抗弁の前提になる。

## 判断基準・使い分け

### 倫理の5段階（条件は累積的）
| 水準 | 取引が倫理的であるための条件 | 含意 |
|---|---|---|
| 1 | 価格が自発的に支払われる | 強制しない。「買い手は用心せよ」 |
| 2 | 加えて、情報が対等である | 既知の欠陥やリスクを隠して売らない |
| 3 | 加えて、必需につけ込まない | 必需品や緊急時に過大な利益を取らない |
| 4 | 加えて、価格がコストで正当化される | 価値に基づくセグメント別価格が疑わしくなる |
| 5 | 加えて、誰でも支払い能力に関係なく入手できる | 市場価格とはほぼ両立しない |

価値に基づくセグメント別価格（[1] 全体の中心となる手法）が倫理的に成り立つのは、水準3までである。自社、業界、顧客がそれぞれどの水準に立っているかを確認する。

### 米国法の論点表
| 論点 | 確認すること | 目安 |
|---|---|---|
| 水平的価格協定（シャーマン法1条） | 競合と価格・条件・割引について合意や情報交換をしていないか | 当然違法である。自社価格の公表は問題ない。並行行為に「プラス要因」（単独なら不利だが全員で行えば有利な行為など）が加わると合意が推認される |
| 価格シグナリング | 価格意図を事前に告知していないか | 買い手の計画を助ける正当な目的があれば通常は適法（*DuPont*）。共謀的・排除的な使い方は避ける |
| 再販価格維持 | 再販業者に売価を指示していないか | 合意は合理の原則で判断される。一方的な方針の公表と、違反した業者への販売停止（*Colgate*）は適法である。警告、脅し、「執行猶予」は合意を推認させる |
| 最低広告価格（MAP） | 広告アローワンスと広告価格を結びつけていないか | 合理の原則で判断される。競合する再販業者に平等な条件で提供する |
| 価格差別（ロビンソン・パットマン法） | 競合する買い手に、同等の物品を異なる価格で売っていないか | 下の5要件がすべて揃うと違法になる。抗弁はコスト正当化（実際の節約額まで）、競争対抗（誠実な信念）、状況変化（生鮮品、季節品、陳腐化品など） |
| 販促差別 | 販促資金やサービスを、競合する再販業者全員が機能的に利用できるか | 比例的に平等な条件が必須。抗弁は競争対抗だけである |
| 垂直的非価格制限 | 顧客・地域・製品を制限していないか | 合理の原則で判断される（*Sylvania*）。ブランド間競争を促すためなら許容される |
| 排他的取引 | 他社製品の購入を禁じていないか | 競合を不合理に締め出さなければ適法 |
| 抱き合わせ（tying） | ある製品の購入を、別の製品の購入の条件にしていないか | 別売りできるバンドルなら通常は該当しない。市場支配力のある企業による強制は危険 |
| 略奪的価格設定（シャーマン法2条） | 増分コスト（限界費用）を下回る価格で、競合の排除を狙っていないか | コスト割れと損失回収の蓋然性の両方が必要（*Brooke Group*） |
| 会計統制（サーベンス・オクスリー法） | 値引きや販促資金が内部統制に含まれているか | 文書化と調査の手順を定める |
| 欺瞞的な二重価格表示（[1] の範囲外） | 「通常価格」「比較価格」が、実在する直近の価格に基づいているか | FTC の指針と州法を確認する。架空の参照価格は使わない |

### 価格差別の5要件（[1] p.303）
1. 差別: 顧客ごとに価格が異なる。全顧客が使える割引を一部が使わないだけなら該当しない。
2. 2者以上への販売: 近い時期に実際に販売している。見積もりだけなら該当しない。
3. 物品: 対象は物品だけで、サービスは含まない。
4. 同等の等級・品質: 物理的・実質的に同じ製品である。
5. 競争侵害の合理的な蓋然性: 競合他社への侵害（一次ライン）か、不利に扱われた再販業者への侵害（二次ライン）がある。二次ラインで同等に扱うべきは、互いに競合する顧客だけである。

## 手順
1. 販売する法域を特定し、レポートに明記する。
2. 倫理の水準を決める。必需品、緊急時、弱い立場の顧客が関わる場合は、その水準で価格案を点検する。
3. 米国法の論点表を上から順に当てはめ、該当する論点ごとにリスクを高・中・低で付ける。
4. セグメント間やチャネル間の価格差ごとに、正当化の根拠を記録する。根拠の種類はコスト差、競合価格への対抗、製品・サービスの差、非競合顧客のいずれかである。
5. 再販価格の方針は、合意ではなく一方的な方針として文書化する。違反への対応は、該当製品の販売停止に限る。
6. 販促プログラムに、全ての競合再販業者が利用できる代替手段があるかを確認する。
7. 日本・EU の確認項目（下記）を当てはめる。該当するものは弁護士レビューの対象として挙げる。

## 日本・EU の確認項目（[1] の範囲外。弁護士の確認が必要）
[1] は米国法だけを扱う。以下は確認すべき論点の目安であり、内容の正確性は保証しない。
- **日本の独占禁止法（再販売価格の拘束）**: 米国より厳しく、原則として違法と扱われる。希望小売価格は「参考」にとどめ、守らせるための不利益な扱いをしない。
- **日本の独占禁止法（不当廉売）**: 供給に要する費用を著しく下回る価格で継続して販売していないか確認する。
- **日本の独占禁止法（差別対価）**: 地域や相手方によって不当に異なる対価を付けていないか確認する。
- **日本の独占禁止法（優越的地位の濫用）**: 取引上の地位が強い場合に、減額、協賛金の要請、返品の強要などをしていないか確認する。
- **日本の景品表示法（二重価格表示）**: 比較対照価格として「最近相当期間にわたって販売されていた価格」の実績があるか確認する。
- **EU の競争法**: 再販価格維持はハードコア制限として扱われる。支配的地位にある企業の差別価格、略奪価格、抱き合わせも厳しく規制される。地域間の並行取引の制限にも注意する。

## よくある失敗と対処
- **法務が過度に保守的になり、価値に基づく価格差を全面的に禁じる。** 論点表で要件を1つずつ確認し、非競合顧客やサービスが対象外であることを示す。
- **再販業者に「次は取引を止める」と警告する。** 警告は合意を推認させる。方針を公表し、違反したら黙って販売を止める。
- **販促資金を大手にだけ出す。** 競合する中小の再販業者にも、代替の手段と比例的な条件を用意する。
- **日本でも米国と同じ前提で再販方針を作る。** 日本では再販売価格の拘束の扱いが大きく異なる。現地の弁護士に確認する。
