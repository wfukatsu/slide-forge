# 価格感応度の測定

価格感応度（価格の変化で購買がどれだけ変わるか）と支払意思額（買い手が払ってよいと考える最大額）を、調査や実験で数字として確かめる方法を扱う。価値カスケード（価値の創造 → 価値の伝達 → 価格構造 → 価格ポリシー → 価格水準 → 価格競争）の各段の仮定、特に価格構造と価格水準を検証する役割を持つ。手法の選択や、発売前後の測定計画に使う。

## 要点

- 測定は経営判断を補うものであり、代わりにはならない。誰が・なぜ・どう買うかの理解が先にある。
- 精密（precise）であることと正確（accurate）であることは別物である。小数点まで出た調査結果もただの調査結果であり、報告は幅で出す。
- 手法は「測定条件（非統制／実験的統制）」×「測定変数（実購買／選好・意向）」の 2×2 で分類する（[1] Exhibit 8-1）。実購買のほうが信頼できるが、高コストで、未発売品には使えない。
- 「最大いくら払うか」を直接聞いてはならない。値切り、迎合、深く考えない即答のいずれかで歪み、有効な手法とは認められない。
- 購入意向調査（buy-response survey）は、受容される価格帯の特定と、時点・条件間の「変化」を見るためだけに使う。販売量の予測には使わない。
- 深層インタビュー（in-depth interview）は価値を直接聞かず、使用状況から推論する。B2B の価値ベース販売の土台になる。
- トレードオフ（コンジョイント）分析（trade-off / conjoint analysis）は価格を属性ごとの価値に分解でき、戦略には最も有用である。ただし価格への注意を人工的に高めるため、価格感応度を過大に出しやすい。
- 過去の販売データは安いが、推定できるのはチャネルの次段階（メーカーなら卸・小売の仕入れ）の価格弾力性（販売数量の変化率 ÷ 価格の変化率）であり、集計・多重共線性・価格変動の不足という問題を抱える。

## 判断基準・使い分け

### 手法の分類（[1] Exhibit 8-1）

| | 非統制（観察する） | 実験的統制（変数を操作する） |
|---|---|---|
| 実購買 | 過去の販売データ、パネルデータ、店舗スキャナー／取引データ、受注・失注記録 | 店頭購買実験、オンラインの A/B 価格テスト、ラボ購買実験 |
| 選好・意向 | 直接質問（使わない）、購入意向調査、深層インタビュー | 模擬購買実験、トレードオフ（コンジョイント）分析 |

右上（統制された実購買）ほど正確で高コストであり、左下（非統制の選好・意向）ほど安いがバイアスが大きい。

### 手法ごとの強みと限界

| 手法 | 強み | 限界・注意 |
|---|---|---|
| 過去の販売データ | ほぼ無料 | チャネルの次段階の弾力性しか出ない。集計で店舗差・特売差が消える。価格が動いていなければ検出できない。広告と常に同時なら多重共線性（説明変数が連動して効果を分けられない状態）で分離できない。観測範囲外の価格には外挿できない |
| パネルデータ | 実際に支払った価格、競合の購買、世帯属性と結び付けたセグメント分析が得られる | 参加世帯の代表性に偏りがある。記録する行為が価格意識を高める |
| 店舗スキャナー／取引データ | 日次・店舗単位で安価 | B2B では取引数が少ない。顧客が申告する競合価格は低めに偏る |
| 店頭購買実験・A/B テスト | 最高品質の推定 | 実店舗は費用が大きい。顧客ごとの価格差で信頼を損なう。競合に見つかると結果が汚染される |
| ラボ購買実験 | 低コストで競合に知られない。統制により少数の購買から推論できる | 単純な環境では価格への注意が過大になる。観察されていると賢く見せる行動が出る |
| 購入意向調査 | 安く速い。購買確率曲線（purchase probability curve、価格ごとの購入意向者の割合）が得られる | 回答は高めに出る。国による文化差がある。実売の予測には使えない |
| 属性評価 | 手軽 | 回答が軽率で肯定的に偏り、ハロー効果（全属性に似た評価を付ける傾向）が出る |
| 深層インタビュー | 価値ドライバー（value driver、買い手にとっての便益の源泉）と価値の大きさを推論できる | 高コストで小サンプル。該当顧客の比率は別途定量調査が要る |
| 模擬購買実験 | 開発前のコンセプトの価格を試せる。複数ブランドからの選択課題にすれば値切り・迎合を抑えられる | 実際の購入は伴わない |
| トレードオフ分析 | 属性別の効用、セグメント別の価格感応度、まだ存在しない組み合わせのシェア予測が得られる | 価格の役割を過大評価しがち。住宅や対面交渉の B2B では方向性の参考にとどまる |

### 状況別の第一候補（[1] pp.201–202）

| 状況 | 第一候補 | 理由 |
|---|---|---|
| コンセプト・プロトタイプ段階 | トレードオフ分析、深層インタビュー、模擬購買 | 過去データも購買実験も使えない |
| 開発済みの低価格・高頻度購買品 | 店頭実験、高度なラボ購買実験 | 買い手は普段価格に注意しないため、調査では感応度が歪む。少数の店頭実験と模擬購買を対にしてバイアスを補正する |
| 開発済みの高額耐久財 | 単純なラボ実験、模擬購買調査 | 買い手が自然に価格へ注意するため、単純な手法でもかなり正確に出る |
| 発売後しばらく経った製品 | 過去の販売データ、受注・失注記録 | 価格変更を広告と同時に行う場合と単独で行う場合に分けておけば、効果を分離できる |
| オンライン販売 | A/B 価格テスト、オンライン模擬店舗 | 低コスト・短期間で実購買に近いデータが取れる |
| ティア構成そのものが論点 | トレードオフ分析 | 属性ごとの効用が分かり、ティアの境界を決められる |

## 手順

1. 判断すべきことを書く。価格水準か、ティア構成か、割引方針か。必要な精度も決める。多くの場合に必要なのは需要曲線そのものではなく、損益分岐販売変化率（価格変更後も総貢献利益を保つのに必要な販売量の変化率。[financial-analysis.md](financial-analysis.ja.md)）を「超えそうか」の判定である。
2. 探索的な定性調査から始める。誰が買い、なぜ買い、どう決めるかを押さえる。価値の推定には総経済価値（total economic value、次善の競合代替品の価格＝参照価値に差別化価値を加えた額）の枠組みを使う（[economic-value.md](economic-value.ja.md)）。
3. 製品の段階と価格帯から、上の表で手法を選ぶ。安い・速い・便利だけを理由に選ばない。
4. 判断を測定設計に組み込む。
   - サンプル: 実際の買い手の属性構成に合わせる（比例サンプリング）。平日日中の調査で勤務者が抜けないか確認する。
   - 外生要因: 季節、特別な行事、競合の欠品などを記録し、分析で除去する。
   - 変数の分離: 価格と販促が常に同時なら、経験則で片方の効果を置くか、別々に実施する。
   - モデル構造: 購買サイクルと在庫行動から実験期間とラグを決める。
   - 製品記述: 言葉で連想が変わる（「耐摩耗性」と「タフ」）。実際の販売での訴求に合わせる。
5. 手法別の実施ポイント。
   - 深層インタビュー: 1〜2 時間の半構造化面談。現在の業務のやり方、コスト、失敗箇所を聞き、価格は聞かない。主要セグメントあたり 10〜12 件で重要なニーズの約 9 割が出る。B2B では喚起的アンカリング（evocative anchoring）を使い、「この便益のために予算のどの項目を削るか」を聞く。
   - 購入意向調査: 回答者ごとに異なる価格を 1 つ提示し、「この価格で買うか」を聞く。集計して購買確率曲線を描き、意向が急落する価格（曲線の膝）を探す。
   - トレードオフ分析: 属性の水準と価格を体系的に変えた組み合わせを選ばせ、各属性の効用と価格感応度を推定する。全体平均ではなくセグメント別に見る（全体では成り立たない高価格が、特定セグメントでは成り立つことがある）。
   - A/B・店頭テスト: 一地域・一チャネル・一コホートに限定し、対照群を置く。期間は購買サイクルより長くする。
   - 過去データ: 多変量回帰で価格以外の要因を統制する。推定値は観測された価格帯の中でだけ使う。
6. 結果を解釈する。最初に「なぜこの結果になったか」を問う。購入意向は高めに、コンジョイントの価格感応度も高めに出ることを前提に読む。
7. 幅で報告し、判断と合わせて結論を出す。推定値は判断を置き換えるものではなく、判断を改める材料として使う。

### 測定計画テンプレート

| 検証する仮定 | 手法 | 時期 | 影響する判断 |
|---|---|---|---|
| 最大の価値ドライバーが想定の大きさで実在する | 深層インタビュー（主要セグメントあたり 10〜12 件） | 発売前 | 参照価値・差別化価値、訴求メッセージ |
| ティア境界が、買い手による機能の優先順位と合う | トレードオフ調査 | 発売前 | オファー構成（[price-structure.md](price-structure.ja.md)） |
| 推奨価格で購入意向が崩れない | 購入意向調査 | 発売前 | 価格水準（[price-level.md](price-level.ja.md)） |
| 割引方針が守られている | 受注・失注記録、例外承認記録 | 発売時から | 方針の見直し（[pricing-policy.md](pricing-policy.ja.md)） |
| 競合の反応 | 市場モニタリング | 最初の 2 四半期 | 競争への対応（[price-competition.md](price-competition.ja.md)） |

受注・失注記録には提示価格、割引、競合、結果を必ず残す。B2B で実購買データに最も近いものであり、発売初日から始める。

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| 「最大いくら払いますか」と聞く | 使用状況から価値を推論する深層インタビューか、価格を固定した購入意向調査に替える |
| 購入意向の割合をそのまま販売予測にする | 受容される価格帯の特定と、変化の比較にだけ使う |
| コンジョイントの価格感応度をそのまま採用する | 価格が並べて比較されるため高めに出る。可能なら実購買データで補正する |
| メーカー出荷データで最終顧客の弾力性を語る | チャネル在庫の影響を除き、次段階の弾力性として解釈する |
| 全体平均だけを見て高価格を諦める | セグメント別に分析する。特定層で高価格が成り立つことがある |
| 精密な数字を正確だと思い込む | 測れない要因を除外しているから精密なのだと理解し、判断で補う |
| 全社一斉の価格変更で効果を測ろうとする | 限定的なテストと対照群を置き、結果を事実として示す |
| 顧客申告の競合価格をそのまま使う | 低めに偏るので補正する |
