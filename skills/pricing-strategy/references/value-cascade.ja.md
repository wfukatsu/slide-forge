# 価値カスケードと戦略的プライシングの原則
このドキュメントは、価値カスケード（価値の創造 → 価値の伝達 → 価格構造 → 価格ポリシー → 価格水準 → 価格競争）の全体像と、それを貫く3原則を扱う。各段の詳細はほかのドキュメントが扱う。価格の相談を受けたら最初に読み、問題のある段と次に読むドキュメントを決める。

## 要点
- 製品・販促・流通は価値を「創る」活動で、価格はその価値を利益として「回収する」活動である。回収できる量の上限は上流で決まる。
- 戦略的プライシングは6段の価値カスケードで整理する。価値の創造 → 価値の伝達 → 価格構造 → 価格ポリシー → 価格水準 → 価格競争の順で、前半3段が価値管理、後半3段が価格管理である。
- 各段の手抜きは「ギャップ」になって利益を漏らす。潜在価値 → 実現価値 → 知覚価値 → 目標価格 → 支払意思額（willingness-to-pay、顧客が払ってもよいと考える最大額） → 実際の価格 → 持続的利益と、段ごとに目減りしていく。
- 3原則は、価値ベース、先行的、利益駆動である。
- コストプラス、顧客主導、シェア主導の3つの考え方には構造的な欠陥があるので使わない。
- 需要曲線を推定して最適化するより、損益分岐販売変化率（価格変更後も総貢献利益を保つのに必要な販売量の変化率）を問う方が実務に合う。
- 価値ベースはコストプラスとプロセスの向きが逆である。顧客 → 価値 → 価格 → コスト → 製品の順に考え、目標価格が許容コストと仕様を決める（[1] Exhibit 1-3）。
- 「価格が高すぎる」という訴えの多くは、価格水準ではなく伝達・構造・ポリシーの問題である。

## 判断基準・使い分け

### 各層の問いと漏れ方
| 層 | 答えるべき問い | 飛ばしたときの典型的な漏れ | 次に読む |
|---|---|---|---|
| 1. 価値の創造 | 顧客が対価を払う便益だけを含んでいるか。目標価格から許容コストを決めているか | 誰も評価しない機能がコストだけを上げる | [economic-value.md](economic-value.ja.md) |
| 2. 価値の伝達 | 顧客は価格を正当化できるほど価値を理解しているか | 機能の羅列になり、買い手が価格だけを見る | [value-communication.md](value-communication.ja.md) |
| 3. 価格構造 | 価格メトリクス（課金の単位）、階層、価格フェンス（セグメント別の価格を適用する条件）がセグメント間の価値差とサービスコスト差を反映しているか | 単一価格のため高価値層から取り損ね、低価値層を逃す | [price-structure.md](price-structure.ja.md) |
| 4. 価格ポリシー | 値引き要求や競合の脅しに対して一貫したルールがあるか | 場当たりの例外から、定価は交渉の出発点だと顧客が学ぶ | [pricing-policy.md](pricing-policy.ja.md) |
| 5. 価格水準 | 許容範囲の中で、スキミング（高価格で高価値層から回収）、浸透価格（低価格で量を取る）、中立価格（価格を購買の決め手にしない）のどれを選ぶか | コストプラスや「顧客が言う額」で決めてしまう | [price-level.md](price-level.ja.md) |
| 6. 価格競争 | 競合の反応を織り込んだうえでも利益が出るか | 全員の利益を削る価格戦争 | [price-competition.md](price-competition.ja.md) |

### 症状から層を診断する
| 症状 | 疑う層 |
|---|---|
| 導入後の顧客も価値を実感していない、または機能の多くが使われていない | 1 創造 |
| 商談で「高い」と言われるが、導入した顧客の満足度は高い | 2 伝達（知覚価値が経済的価値を下回っている） |
| 大口顧客にも小口顧客にも同じ価格で、どちらかに不満がある | 3 構造 |
| 値引き率が四半期ごとに広がり、例外承認が常態化している | 4 ポリシー |
| 価値も構造も整理済みで、あとは数字を決めるだけになっている | 5 水準 |
| 競合の値下げに追随するかどうかを迷っている | 6 競争（加えて3と4） |

### 避けるべき3つの考え方
| 考え方 | 欠陥 | 置き換える問い |
|---|---|---|
| コストプラス | 単位コストは販売量で変わり、販売量は価格で変わるため循環する。弱い市場では高すぎ、強い市場では安すぎる価格になる。固定費を回収しようと値上げして量が減る「死のスパイラル」に陥る | 実現できる価格を前提に、どこまでのコストなら許容できるか |
| 顧客主導 | 顧客が「払う」と言う額に合わせると、買い手は価値を隠すことを学ぶ。支払意思額を価値に近づけるという営業の仕事を放棄することになる | この顧客にとっての価値はいくらで、どう伝えれば価格を正当化できるか |
| シェア主導 | 値下げはすぐ真似されるので、得られる優位は一時的で、低いマージンだけが恒久的に残る | 最も利益が出るシェアの水準はどこか |

## 手順
1. 相談内容を1文にまとめ、上の診断表で最も上流の疑わしい層を特定する。下流の症状（値引き、競合の値下げ）でも、上流に原因があれば上流から直す。
2. 層1と層2を確認する。対象セグメント、次善の競合代替品（自社がなければ顧客が選ぶもの）、上位の価値ドライバー（顧客の経済性や満足を左右する要因）が言語化されていなければ、[economic-value.md](economic-value.ja.md) から始める。
3. 層3と層4を確認する。価格メトリクス、オファー構成（何をどの階層・組み合わせで売るか）、価格フェンス、値引き規則が文書化されているかを見る。
4. 層5で価格水準を決める。候補の価格変更ごとに損益分岐販売変化率を計算し、想定される需要反応と比べる。貢献利益（CM: contribution margin）は価格 − 単位あたり増分コスト（販売量に応じて増える費用）、貢献利益率はそれを価格で割った比率である。
   ```
   損益分岐販売変化率 = −ΔP / (CM + ΔP)
     ΔP: 価格変化率（値下げは負）  CM: 変更前の貢献利益率
   例: CM 20%で10%値下げ → 0.10/(0.20−0.10) = +100%
       CM 70%で10%値下げ → 0.10/(0.70−0.10) ≒ +17%
       CM 30%で10%値上げ → −0.10/(0.30+0.10) = −25%（25%減までは利益が減らない）
   ```
   価格変更ごとの値を結ぶと損益分岐販売曲線になる（[1] Exhibit 1-1）。実際の需要がこの曲線より急（非弾力的）なら値上げが有利、緩やか（弾力的）なら値下げが有利と判断する。詳しい計算は [financial-analysis.md](financial-analysis.ja.md) と、損益分岐販売変化率を計算する scripts/pricing/breakeven.py を使う。
5. 層6で競合の反応を予測し、反応された後でも利益が出るかを確かめる（[price-competition.md](price-competition.ja.md)）。
6. 3原則で結論を点検する。価値の差が価格の差になっているか（価値ベース）、反応や要求を先回りしているか（先行的）、評価指標がシェアではなく利益になっているか（利益駆動）。
7. 組織面の障害（誰が価格を決めるのか、必要な情報があるか、営業の報酬が売上だけで決まっていないか）があれば [pricing-capability.md](pricing-capability.ja.md) に回す。

## チェックリスト
- [ ] 問題がどの層にあるかを明示し、その理由（症状）を書いている
- [ ] 価格水準の議論より先に、価値（層1）と伝達（層2）の状態を確認している
- [ ] 価格の根拠がコストの積み上げや「顧客が払うと言った額」ではなく、顧客価値になっている
- [ ] 目標価格から許容コストや仕様を逆算する向きで議論している
- [ ] 価格変更案に損益分岐販売変化率が添えてある
- [ ] 成否を貢献利益で評価し、シェアや販売量で評価していない
- [ ] 競合の反応と顧客が交渉で学習することを考慮している
- [ ] 意思決定権、情報、インセンティブという組織の障害に触れている（該当する場合）

## よくある失敗と対処
| 失敗 | 対処 |
|---|---|
| 「値下げすれば売れる」と層5だけで解こうとする | 診断表で上流を確認する。知覚価値が低いことが原因なら、正解は値下げではなく伝達である |
| 固定費を配賦した単位コストに利益を上乗せする | 増分コストだけで貢献利益を計算し、固定費は価格の根拠にしない |
| 顧客満足度を成果とみなす | 満足は過小価格でも買える。価値の回収率と貢献利益で測る |
| シェア目標のために値下げする | 競合が追随できないかどうかを確かめる。追随されるなら恒久的な利益減になる |
| 弾力性を精密に推定しようとして時間を使う | 損益分岐販売変化率を出し、実際の反応がそれを超えそうかを判断すれば十分である |
| 価格決定を営業に任せきりにする | ポリシーと承認ルールを先に決め、営業には価値を売る道具を渡す |
