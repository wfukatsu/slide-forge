# 価格競争への対応

競合の値下げや低価格品の参入にどう応じるか、自社から値下げを仕掛けてよいのはいつかを扱う。価値カスケード（価値の創造 → 価値の伝達 → 価格構造 → 価格ポリシー → 価格水準 → 価格競争）の最後の段で、決めた価格を競合の動きから守る判断にあたる。こうした場面が生じたときに、対応の要否を 5 つの問いで判定し、反応するならコスト最小の形に絞るために使う。

## 要点

- 価格競争は通常マイナスサム・ゲーム（negative-sum game、競うほど全体のコストが増えるゲーム）である。値下げで市場全体の需要がほとんど増えず、各社のコスト構造が似ているほど、勝者も含めて全員が傷つく。手本はスポーツ（プラスサム）ではなく戦争と外交である。
- 構造は囚人のジレンマに近い。単独で値下げすれば得に見えるが、全社が値下げすると全員の利益が下がる。競合が「値下げしても得にならない」と予想できる状態を作る。
- 市場シェア神話（market-share myth、シェアを取れば利益は後からついてくるという思い込み）を捨てる。シェアと利益の相関はどちらも持続的な競争優位の結果にすぎず、値下げで買ったシェアに利益はついてこない。
- 競争優位（competitive advantage）の源泉は、低コスト、製品価値（プレミアムを払わせる力）、独自の顧客アクセスである。尺度は市場シェアではなく、競合と比べた販売 1 件あたりの粗利（相対粗利率、relative gross margin）である。
- 競合の値下げに反応するかは、5 つの問い（[1] Exhibit 7-1）で順に判定する。「反応する」に至る経路は、すべて「対応コスト < 防げる損失」の定量判断を通る。
- 反応する場合も、全顧客への一律値下げは避ける。狙われている顧客、リスクにある増分数量、競合のほうが多くを失う市場に絞るか、価格以外の価値で対抗する。
- 価格戦争の多くは情報不足と誤読から始まる。競合の価格と意図を体系的に集め、自社の意図と能力は選択的に開示する（シグナリング）。
- 低価格で利益ある成長ができるのは、増分コスト優位、競合が反応しないニッチ、補完製品による内部補助、市場拡大の 4 条件のいずれかが成り立つときだけである。

## 判断基準・使い分け

### ゲームの型

| 型 | 競争過程の効果 | 例 | 価格での含意 |
|---|---|---|---|
| プラスサム（positive-sum） | 競うほど全体の便益が増える | 新製品、サービス改善、価値の伝達、業務効率化 | 持続的な戦略の基盤にする |
| マイナスサム（negative-sum） | 競うほど全体のコストが増える | 価格だけの競争、価格戦争 | 勝てる構造があり、便益がコストを上回ると計算できるときだけ戦う |

### 競争優位の源泉（Porter の 3 つのポジショニング）

| 源泉 | 中身 | 価格での使い方 |
|---|---|---|
| ニーズ基盤（needs-based） | 特定セグメントのニーズに業務を最適化する | そのセグメントでプレミアムか低コストを実現する |
| アクセス基盤（access-based） | 地理や顧客規模に由来する独自の顧客接点 | 競合より安く届けられる経路で競う |
| フォーカス基盤（focus-based） | 業界横断で価値を加える狭い活動に特化する | 模倣できない知見に対して価格を取る |

価値の優位もコストの優位もない状態を「中途半端（stuck in the middle）」という。この状態で価格による成長を狙うのは自殺行為である。

### 対応の選択肢

| 対応 | 選ぶ条件 |
|---|---|
| 受け入れる／無視する（accommodate / ignore） | 対応コストが防げる損失を上回る。競合が再値下げで価格差を戻せる。他市場への波及がない |
| 防衛（選択的反応） | 対応コストが防げる損失を下回り、競合が価格差を再構築できない |
| 戦略的防衛 | 他市場（地域・製品）の地位が脅かされ、その市場の価値が対応コストを正当化する |
| 攻撃（自ら値下げ） | 次の 4 条件のいずれかが成り立つ |

### 積極的な価格戦略が報われる 4 条件（[1] pp.170–171）

| 条件 | 確認すること |
|---|---|
| 1. 増分コスト優位 | 増分コスト（その販売によって追加で発生するコスト）が競合より十分低く、競合が追随できないか。価格差をコスト差より小さく保てるか |
| 2. 反応されないニッチ | 自社オファーが競合市場のごく一部にしか魅力がなく、競合が反応する理由がないか |
| 3. 補完製品による内部補助 | 補完製品の利益で損失を埋められ、競合にはそれができないか |
| 4. 市場拡大 | 値下げで市場が十分に広がり、競合が追随しても業界の利益が増えるか |

## 手順

1. 脅威を定義する。競合、値下げ幅、対象のセグメント・地域・製品、開始時期を特定する。
2. 反応的損益分岐販売変化率を計算する。追随しない場合の販売損失がこれを超えれば追随が得になる、という閾値である。貢献利益（CM: contribution margin）は価格 − 単位あたり増分コスト、貢献利益率はその価格に対する割合である。導出と数値例は [financial-analysis.md](financial-analysis.ja.md)（価格変更の損益分岐分析）の「反応的価格変更」にある。

   ```
   反応的損益分岐販売変化率 = 価格変化率 / 貢献利益率
   例: 15% の追随値下げ、貢献利益率 45% → −15% / 45% = −33.3%
   追随しないと販売が 33.3% を超えて失われると見込むときだけ、追随が有利
   ```

   競合の値上げに追随しない場合も同じ式で、必要な販売増（上の例なら +33.3%）を出せる。
   値下げへの追随は `scripts/pricing/breakeven.py`（候補価格ごとの損益分岐販売変化率を計算する）に `--price <現行> --cost <増分コスト> --candidates <追随価格> --reactive` を渡して出す（JSON 入力なら `"reactive": true`）。現行より低い候補ごとに、この閾値を通常の損益分岐とは別の表で出力する。
3. 5 つの問い（[1] Exhibit 7-1）に順に答える。
   1. 防げる売上損失より安く済む対応はあるか。「防げる」損失は現実的に見積もる（価格を合わせても戻らない顧客を除く）。Yes なら問い 2、No なら問い 4 へ。
   2. 対応したら、競合はさらに値下げして価格差を再構築するか。シェアが小さく価格以外の武器がない競合や、埋没費用（すでに支出し回収できない費用）が大きく退出障壁（exit barriers）になっている競合はそうする。No なら反応し、Yes なら問い 3 へ。
   3. 何度も対応し続ける総コストは、回避できる売上損失より小さいか。最初の一手ではなく価格戦争全体のコストで比べる。Yes なら反応し、No なら問い 4 へ。
   4. 問い 1 か 3 が No でも、競合がシェアを得ると他の市場（地域・製品）での自社の地位が危うくなるか。No なら受け入れる／無視し、Yes なら問い 5 へ。
   5. そのリスク市場の価値は対応コストを正当化するか。概算でよいので定量化する。Yes なら反応し、No なら受け入れる。
4. 反応すると決めたら、コストが最小になる形を選ぶ。
   - 狙われている価格感応度の高い顧客だけに側面オファー（flanking offer、価値の低い要素を削った低価格版）を出し、後で引き揚げられる形にする。
   - リスクにある増分数量だけを守る（例: 前年購入量の 80% を超える分にだけ競合水準の割引を出す）。
   - 競合が自社より多くを失う市場で応戦する（競合の本国市場、競合の主力製品）。
   - 競合の値下げコストを上げる（競合の既存顧客に新規客だけが安いと知らせる、最低価格保証を掲げる）。
   - 価格ではなく自社の競争優位で価値を上げる。競合が真似すると自社より高くつくオファーにする。
   - 対象を絞るには価格フェンス（買い手の属性や購買条件で価格を分ける条件）を使う。設計は [price-structure.md](price-structure.ja.md)（価格構造と価格フェンス）と [pricing-policy.md](pricing-policy.ja.md)（値引き・例外の運用）を参照する。
5. どの対応も売上を譲るより高くつくなら、シェアを譲ってマージンを守り、得たキャッシュをコスト効率化と価値向上に回す。
6. 「戦略的理由」で報復値下げを通す前に、長期の便益（将来の追加売上、補完品の売上、コスト優位）とリスク（値下げの他顧客・他市場への波及、下方スパイラル）を文書で明記させる。
7. 競争情報を管理する。
   - 収集: 営業のコールレポートに競合価格を記載させて集約する。忠実な顧客、業界団体、アナリスト、流通業者、店頭調査も使う。意図（合併の狙い、投資計画）も集める。
   - 検証: 購買担当者の「競合が安く出した」は割り引いて聞く。受注時に「安すぎた」と言う顧客はいないので、営業は自社価格を高すぎると思い込みやすい。
   - 発信: 値上げは理由を公に説明し、実施日の十分前に告知する。防衛の意思は最低価格保証や先買権（right of first refusal）条項で示す。コスト優位で攻めるなら、その優位が決定的であることを競合に納得させる情報を先に出す。
   - 反応を速くする。3 週間ではなく 1 週間で反応できれば、機会主義的な値下げの便益は 3 分の 2 減る。
8. 自社から値下げを仕掛ける場合は、上の 4 条件のどれに該当するかを明記する。該当しなければ価格以外の手段に切り替える。

## チェックリスト

- [ ] 反応的損益分岐販売変化率（価格変化率 / 貢献利益率）を計算し、予想販売損失と比べた
- [ ] 「防げる」損失から、価格を合わせても戻らない販売を除いた
- [ ] 競合の再値下げ能力（シェア、コスト構造、退出障壁）を評価した
- [ ] 価格戦争の総コスト（複数回の対応）で比較した
- [ ] 他市場への波及リスクと、その市場の価値を定量化した
- [ ] 対応を全顧客一律ではなく、対象顧客・増分数量・市場に絞った
- [ ] 価格以外の対抗策（価値の追加、価格フェンス付きの側面オファー）を検討した
- [ ] 自社の値下げが意図どおりに読まれるか（シェア奪取と誤読されないか）を確認した
- [ ] 積極的な値下げなら、4 条件のどれに当たるかを明記した
- [ ] 変動費を下回る価格にしていない（略奪的価格の法的リスクは [ethics-legal.md](ethics-legal.ja.md)）

## よくある失敗と対処

| 失敗 | 対処 |
|---|---|
| あらゆる値下げに反射的に追随する | 反応的損益分岐販売変化率と 5 つの問いを通してから決める |
| シェア目標のために値下げする | シェアは結果であり目標ではない。相対粗利率で優位を測る |
| 一部顧客への脅威に全売上の値下げで応じる | 側面オファー、増分数量への割引、地域限定で範囲を絞る |
| 大手なら消耗戦で小規模競合を追い出せると考える | 変動費を下回る価格は独占禁止法違反になりうる。追い出しても、破綻資産を安く買った新規参入者が戻ってくる |
| 「戦略的理由」で数字のない報復値下げを承認する | 長期の便益とリスクを明記させ、リスク市場の価値を概算させる |
| 購買担当者の語る競合価格を鵜呑みにする | 競合価格を体系的に監視し、誇張を見抜ける状態にする |
| 情報を秘密にしすぎて、競合の過剰投資や投げ売りを招く | 業界の見通しや値上げの理由を公に説明する |
| 後で誤りと分かる情報を流す | 信頼を失い、以後のシグナルが効かなくなる。事実に基づく情報だけを出す |
