# Pricing strategy glossary (English–Japanese)

This glossary lists 222 key terms used in value-based pricing strategy, with English, Japanese, and a definition for each. Use it to check translations when reading English literature and materials, and as a standard for aligning terminology within your organization. The definitions summarize how the terms are used in reference [1]. When a term is used with different meanings in different themes, each definition is given with the theme name in parentheses (for example, "(Financial analysis) …").
