# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Purpose

This is a workspace for creating slide presentations. Use the `/slidev` skill for Slidev-based Markdown presentations or the `/scalar-slides` skill for Scalar-branded PPTX slides.

## Slidev Reference

Slidev docs are at https://sli.dev (pre-approved for WebFetch). When creating a Slidev project, use `npm init slidev` to scaffold.
